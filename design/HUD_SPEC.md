# Legend of ToneDa — N64-inspired HUD and Menus

## In-game HUD
- Top-left: 5 heart health icons, later expandable.
- Top-right: equipped GlockNina, T1 shield, contextual action buttons.
- Bottom: compact rhythm prompt (sound slots, playback timing, sequence feedback).
- Interaction: Niggy attention cue → red/gold bordered text box → typewriter text → advance indicator.
- Lock-on: target marker, enemy health and circling movement.
- Small contextual objective banner, optional mini-map later.

## Title
Use licensed user-provided Hyrule track when uploaded. Start Game / Continue / Options, cover-inspired red, black and gold. Keyboard, touch and controller focus states.

## Pause menu
Equipment, Songs, Map, Quests, Settings. Preserve current game state.

## Accessibility
Subtitles on by default, adjustable text speed, independent music/voice volume, reduced flashes, controller remapping later.

## Production
Create original textures and iconography, no Nintendo UI art. This file is design guidance, not implemented UI.
