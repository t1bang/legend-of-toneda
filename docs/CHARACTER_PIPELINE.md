# Character pipeline

ToneDa's two forms are **built from the approved turnaround artwork**. The game loads
`assets/models/yn-toneda.glb` and `assets/models/og-toneda.glb`, which show that artwork
itself wrapped onto rounded body parts and weighted to a 25-bone skeleton. They are
generated by `tools/artmodel/` (see its README) and are exact from the front and back,
approximate from the sides.

The T1 shield is `assets/models/t1-circular-shield.glb`, strapped to the left forearm bone.

If a model file fails to load, that form falls back to an older stand-in built from simple
shapes in `toneda.js`. The animation clips in `anims.js` drive either one, because both use
the same bone names.

| File | What it does |
| --- | --- |
| `src/character/meshkit.js` | Low-poly modelling helpers (lofted tubes, boxes, cones, patches) that write bone weights per vertex |
| `src/character/textures.js` | 128x128 pixel-art atlas drawn in code: both faces and the T1 logo |
| `src/character/toneda.js` | The `ToneDa` controller (animation blending, cape motion, YN/OG swap), the GlockNina prop, and the stand-in model |
| `src/character/anims.js` | Every animation clip, written as bone poses |
| `src/character/art.js` | Loads the art-built `.glb` models and the shield, and attaches the shield and GlockNina to their bones |
| `tools/artmodel/` | Python scripts that turn a turnaround image into a rigged `.glb` |
| `src/character/niggy.js` | Niggy: orb, bat wings, seven swappable faces, glow, flames, hover/flap/spin |
| `src/world.js` | Trap Village: cliffs, trees, paths, the Trap House, treetop huts and stump homes (all walk-in, with furnished rooms), Great Trap Tree, pond, stall, plus collision |
| `src/items.js` | Things to use: the flower pot (lift, carry, throw, smash), gold rings, treasure chests and what comes out of them |
| `src/touch.js` | The on-screen joystick for phones and tablets |
| `src/game.js` | The game itself: the opening in the tree house, the Switch mission, dialogue, controls, camera, shooting |
| `viewer.html` | Model viewer: spin either form, play any clip, try Niggy's expressions |

## Clips
idle, walk, run, sprint, jump, fall, land, roll, punchR, punchL, kick, fire, block, hurt, transform, song.

`block`, `walk`, `hurt` and `song` exist and play in the viewer but are not wired to gameplay yet.

## Niggy
His seven faces are the creator's own art, cut from the faces sheet into 512x512 transparent PNGs in `assets/niggy/`.
If one fails to load, a simpler code-drawn face is used instead.
Expressions: idle, talking, laughing, mad, surprised, confused, hurt.

## Using it
```js
const toneda = new ToneDa();
scene.add(toneda.root);
toneda.update(dt, { moving, sprint, grounded, vy }); // every frame
toneda.play('punchR');      // one-shot
toneda.transform(true);     // YN -> OG
```

## Changing the look
- Colours: `PAL` at the top of `toneda.js`.
- Body proportions: `SPECS` in `toneda.js`.
- Faces: `drawFaceYN` / `drawFaceOG` in `textures.js`.

## Swapping in a sculpted model later
If a `.glb` model is made in Blender or a 3D generator, it can replace the
code-built mesh as long as its bones use the same names (`hips`, `spine`,
`chest`, `armL`, `foreL`, ...). The clips in `anims.js` target bones by name.
